## 1. 文档概述

### 1.1 文档目的

本文档为个人知识库系统的产品需求说明书，用于明确系统定位、用户角色、核心功能、后台管理能力、交互规则、数据模型及验收标准，为后续 UI 设计、开发实现、测试验收、迭代优化提供统一、可落地的依据。

### 1.2 产品定位

一款**轻量化、私有化**的个人知识管理工具。面向个人用户，聚焦笔记记录、知识分类归档、内容检索、文章后台管理四个核心能力，帮助用户沉淀碎片化知识、系统化管理学习/工作笔记，支持长期知识积累与快速查阅。无冗余功能，主打简洁、高效、易用。

### 1.3 目标用户

| 用户类型 | 典型诉求 |
|----------|----------|
| 职场从业者 | 沉淀项目经验、工作总结、会议记录 |
| 学生 | 整理课程笔记、复习资料 |
| 自学爱好者 | 系统化归档学习内容，快速检索 |

**核心用户特征**：单人使用为主；需要长期积累、跨场景分类、快速找回内容；对数据私密性要求高。

### 1.4 需求范围

**本次迭代范围**：前端笔记操作功能 + 后台管理功能。包含笔记增删改查、富文本编辑、分类标签管理、全文检索、收藏置顶、回收站、数据统计、数据备份与导出、文章公开/私有权限。

**不在本次范围**：多人协作、评论互动、付费能力、移动端 App（仅保留基础移动端网页适配）、社交分享。

### 1.5 术语表

| 术语 | 定义 |
|------|------|
| 笔记/文章 | 系统内知识内容的载体，含标题、正文、分类、标签等属性 |
| 分类 | 一级/二级树形结构，用于内容归档，一篇笔记归属一个主分类 |
| 标签 | 扁平的跨维度标记，一篇笔记可绑定多个标签 |
| 回收站 | 笔记软删除后的暂存区，可恢复或永久删除 |
| 置顶 | 将重要笔记固定在列表顶部的标记 |
| 私有/公开 | 私有：仅登录用户可见；公开：匿名访客可访问（仅查看） |

## 2. 整体产品架构

系统分为两大端，逻辑隔离、复用同一套数据：

```
┌─────────────────────────────────────────────┐
│              个人知识库系统                    │
├──────────────────────┬──────────────────────┤
│   用户前端（内容端）     │   管理后台（运维端）     │
│  · 笔记撰写/编辑        │  · 文章批量运维          │
│  · 分类/标签浏览筛选     │  · 分类/标签统一管理      │
│  · 全文检索             │  · 数据统计看板          │
│  · 收藏/置顶/回收站      │  · 数据备份/恢复/导出     │
│  · 公开文章浏览（访客）   │  · 系统基础设置          │
└──────────────────────┴──────────────────────┘
```

**权限边界**：访客仅能访问「公开」文章列表及详情；登录用户可操作前端全部功能；后台仅登录用户可访问。

## 3. 功能需求（前端用户端）

### 3.1 账号与登录

- 首次使用需初始化账号（用户名 + 密码），初始化后自动登录；
- 登录态持久化：会话有效期内免登录（默认 30 天），支持手动退出；
- 支持修改登录密码（后台设置中提供）。
- **交互**：登录失败提示原因（账号不存在 / 密码错误）；忘记密码场景在单机部署下通过数据重置处理，V1 不做找回密码。

### 3.2 笔记新增与编辑

**核心场景**：用户日常记录学习笔记、工作心得、碎片化知识点。

功能细则：

- 支持新建空白笔记，自定义标题、正文；
- **富文本编辑器**支持：加粗、斜体、下划线、删除线、标题层级（H1~H3）、段落、有序/无序列表、引用、代码块、分割线；
- 支持插入本地图片（上传后存储）、超链接；图片支持缩放、删除；
- **实时自动保存**：输入停顿 2s 后自动保存，保存成功轻提示（不打断输入）；同时支持 `Ctrl/Cmd + S` 手动保存；
- **草稿恢复**：未保存完成的笔记在再次打开时提示「检测到未保存的草稿，是否恢复？」；草稿保留 7 天，避免内容丢失；
- 支持编辑已有笔记，保存后覆盖原内容，更新时间自动刷新；
- **编辑页离开保护**：存在未保存内容时离开页面弹确认提示。

### 3.3 知识分类管理

**核心场景**：对所有笔记结构化归档，避免内容杂乱。

功能细则：

- 支持**两级分类**（一级 + 二级子分类），如：工作 → 项目复盘 / 工作总结；学习 → 编程笔记 / 读书笔记；
- 用户可新增、编辑、删除分类；分类属性：名称、排序序号、上级分类（可选）；
- 新建/编辑笔记时绑定主分类（唯一）；笔记可属于「未分类」；
- **删除校验**：
  - 分类下有二级分类时：需先处理子分类（迁移或一并删除）；
  - 分类下有笔记时：提示迁移到其他分类或移入回收站后再删除，禁止直接误删；
- 前端支持按分类筛选：点击分类树节点查看该分类（含其子分类）下所有笔记，列表展示笔记数。

### 3.4 标签管理

功能细则：

- 用户可自定义创建、编辑、删除标签（全局通用，不归属分类）；
- 单篇笔记支持绑定多个标签；标签支持自动补全（输入时联想已有标签）；
- 前端支持按标签筛选笔记；点击标签跳转至该标签下所有笔记列表；
- 删除标签仅解除绑定关系，不影响笔记本身。

### 3.5 笔记浏览与检索

**3.5.1 笔记列表**

- 默认按更新时间倒序展示；展示字段：标题、简介（正文摘要前 100 字）、分类、标签、创建/更新时间；
- 支持分页（默认每页 20 条，可选 10/20/50）或滚动加载；
- 支持**置顶**：置顶笔记固定展示在列表最前，置顶内部仍按时间排序；
- 支持列表视图/简洁视图切换（可选）。

**3.5.2 全文检索**

- 支持关键词搜索，匹配范围：标题、正文、分类名称、标签名称；
- 检索结果**高亮**展示匹配片段，支持模糊匹配（中文分词按连续字符匹配）；
- 支持筛选条件组合：分类 + 标签 + 关键词；
- 无结果时展示空态引导（如「换个关键词试试」），并提供一键清空筛选；
- **性能要求**：千篇级笔记下检索响应 ≤ 1s（实现层面建议使用全文索引，见 §8）。

### 3.6 笔记基础操作

- **查看**：点击标题进入详情页，完整渲染图文内容；
- **编辑**：详情页 / 列表页均可快捷进入编辑态；
- **删除**：单篇删除 → 移入回收站（软删除），可恢复、可永久删除；列表页支持多选批量删除；
- **收藏**：支持收藏重点笔记，收藏列表单独展示；收藏状态在列表/详情页可视化标记；
- **权限设置**：新建/编辑时可选权限状态（私有/公开），默认**私有**；
  - 私有：仅登录本人可见；
  - 公开：匿名访客可访问（仅查看，不可编辑/删除）。

## 4. 功能需求（后台管理端）

后台为个人专属管理端口，无多角色权限，主打高效运维与批量管理。

### 4.1 文章（笔记）管理

- **文章列表**：全量展示所有笔记，字段含 ID、标题、分类、标签、权限状态（公开/私有）、置顶状态、创建/更新时间、状态（正常/回收站）；
- **列表筛选**：按状态（正常/回收站）、分类、权限、关键词组合筛选；
- **单篇操作**：新增、编辑、查看、删除、置顶/取消置顶、切换公开/私有；
- **批量操作**：批量迁移分类、批量添加/移除标签、批量切换权限、批量删除、批量恢复、批量永久删除；
- **回收站**：区分正常/回收站笔记；回收站支持单条恢复、批量恢复、永久清空（需二次确认）；
- **内容导出**：单篇/批量导出为 Markdown / TXT 格式（批量打包为 zip），用于备份留档。

### 4.2 分类管理

- 展示全部分类树形结构，清晰呈现一级/二级归属；
- 支持新增上下级分类、改名、调整排序（拖拽或序号）、删除；
- 每个分类展示笔记数量；支持按笔记数排序，直观掌握内容体量；
- 删除逻辑与前端一致（§3.3 删除校验）。

### 4.3 标签管理

- 展示所有标签 + 各标签绑定笔记数；
- 支持新增、编辑、删除；支持**批量清理空标签**（绑定数为 0 的标签一键删除）；
- 支持标签名搜索定位。

### 4.4 数据统计看板

统计维度：

- 总量：总笔记数、总字数（可选统计）；
- 增量：今日新增、本周新增、本月新增；
- 分布：各分类笔记数量占比（柱状图/饼图）；
- 状态：收藏数、回收站数、公开文章数；
- 趋势：近 30 天笔记新增趋势折线图（可选，作为 V1.1 增强）。

### 4.5 系统基础设置

- **账号设置**：修改昵称、修改登录密码（需验证原密码）；
- **数据备份**：一键导出全量数据（JSON + Markdown 双格式）；支持本地文件导入恢复（导入前强制备份提示）；
- **基础配置**：默认列表排序方式、编辑器默认格式（如默认字体/段落间距）、每页条数等个性化项。

## 5. 权限需求

| 角色 | 可访问内容 | 可执行操作 |
|------|-----------|-----------|
| 登录用户（本人） | 全部笔记 + 后台 | 前端全部操作 + 后台全部管理功能 |
| 匿名访客 | 仅「公开」笔记列表与详情 | 仅浏览 |

- 唯一管理员/用户，登录后可操作前端所有功能、后台所有管理功能；
- 所有页面（除公开浏览页、登录页外）均需登录校验；未登录访问受保护页面 → 重定向登录页；
- 支持登录态留存（默认 30 天免登录），支持手动退出；
- 接口层面：所有写操作接口强制鉴权，拒绝未授权请求。

## 6. 数据模型设计（实体关系）

```
users（用户）
  id, username(唯一), password_hash, nickname, created_at

categories（分类）
  id, name, parent_id(空=一级), sort, created_at

tags（标签）
  id, name(唯一), created_at

articles（笔记）
  id, title, content(富文本 HTML), summary(简介，自动生成),
  category_id(可空), status(normal/trash), visibility(private/public),
  is_pinned(bool), is_favorite(bool),
  created_at, updated_at, deleted_at(入回收站时间)

article_tags（笔记-标签 多对多关联）
  article_id, tag_id
```

**关键规则**：
- 文章删除为软删除（status=trash + deleted_at），永久删除为硬删除并级联清理关联标签；
- 分类删除需满足 §3.3 校验；删除分类不删除笔记（改为未分类），仅删除时用户明确选择迁移目标；
- 全文检索依赖 content/title 索引（见 §8 技术建议）。

## 7. 技术架构建议（参考，可在技术设计阶段确认）

> 本节为落地参考建议，非需求强约束；最终选型由开发阶段确定。

**推荐轻量方案（单用户、低成本部署）**：

| 层级 | 推荐 | 备选 |
|------|------|------|
| 前端 | Next.js (App Router) + TypeScript | Vue 3 + Vite |
| 富文本编辑器 | TipTap（易扩展、Markdown 友好） | wangEditor / Quill |
| 后端 | Next.js API Routes（全栈单应用） | NestJS / FastAPI |
| 数据库 | SQLite（零运维，单机够用） | PostgreSQL（若长期云部署） |
| 全文检索 | SQLite FTS5 / PostgreSQL tsvector | MeiliSearch（千篇以上强检索需求） |
| 认证 | JWT + HttpOnly Cookie | Session |
| 密码存储 | bcrypt / argon2 加盐哈希 | — |
| 部署 | Docker 单容器（本地 NAS / 轻量云 1C2G） | Vercel + Neon |

**安全要点**：富文本内容必须做 XSS 消毒（服务端白名单过滤）；图片上传限制类型与大小（建议 ≤ 5MB）；接口统一鉴权中间件。

## 9. 非功能需求

### 9.1 性能

- 页面首屏响应 ≤ 1.5s；笔记检索响应 ≤ 1s（千篇笔记量级）；
- 千篇以上笔记列表加载、筛选无卡顿（分页/虚拟滚动）；
- 自动保存低延迟（≤ 500ms 内发起请求），不阻塞输入。

### 9.2 兼容性

- 兼容 Chrome、Edge、Firefox、Safari 最新两个大版本；
- PC 端完整功能；移动端基础适配：可浏览、可编辑（自适应布局）。

### 9.3 安全

- 密码 bcrypt 加盐哈希存储，禁止明文；
- 富文本内容服务端 XSS 消毒，防止存储型 XSS；
- 所有页面/接口登录校验；接口统一鉴权，防未授权访问；
- 笔记数据本地 + 服务端双重保障（自动保存 + 手动备份导出）。

### 9.4 易用性

- 界面简洁干净，无广告无冗余功能；
- 新建、分类、检索三步内完成；
- 关键操作二次确认：删除分类、永久删除、清空回收站、数据导入覆盖；
- 操作反馈：保存成功/失败均有明确提示。

## 11. 迭代规划

### M1 · 基础闭环（P0）
登录注册 → 笔记 CRUD → 富文本编辑 → 自动保存/草稿 → 一级分类 + 标签 → 列表/详情 → 权限（私有/公开）

### M2 · 效率提升（P0 收尾 + P1）
全文检索 + 高亮 → 收藏/置顶/回收站 → 二级分类 → 分类/标签筛选 → 批量操作 → 数据看板

### M3 · 运维完善（P1 + P2）
导出（MD/TXT）→ 备份/导入恢复 → 系统设置 → 移动端适配 → 可选增强项

## 12. 验收标准

### 12.1 功能验收

1. 笔记新增 → 编辑 → 自动保存 → 删除 → 回收站恢复 → 永久删除，全流程闭环无异常；
2. 草稿恢复：编辑中断后重开页面可恢复未保存内容；
3. 分类/标签增删改查正确，删除校验生效（有子分类/有笔记时禁止直接删除）；
4. 检索精准：标题/正文/分类/标签四维匹配，结果高亮，空结果有引导；
5. 收藏、置顶、分页、排序逻辑正确；
6. 后台全部管理功能正常：批量迁移/批量删改/回收站清空/导出；
7. 数据看板统计准确（与真实数据一致）；
8. 备份导出文件可正常导入恢复，数据无丢失。

### 12.2 权限验收

9. 未登录无法访问私有内容及后台，重定向登录页；
10. 公开文章匿名可访问（仅查看）；私有文章匿名不可见；
11. 权限切换（公开↔私有）实时生效；批量权限配置生效。

### 12.3 非功能验收

12. 千篇笔记量级下，首屏 ≤ 1.5s、检索 ≤ 1s；
13. 四款主流浏览器最新两个版本功能正常；
14. 密码非明文存储；富文本粘贴恶意脚本（如 `<script>`）被过滤，不执行；
15. 关键操作（删除、清空、导入覆盖）均有二次确认。

---

## 13. 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 富文本 XSS 注入 | 中 | 服务端白名单消毒 + 前端渲染前过滤，见 §9.3 |
| 数据丢失（误删/崩溃） | 高 | 软删除 + 回收站 + 自动保存 + 定期备份导出 |
| 单机部署硬件故障 | 高 | 提供一键全量备份（JSON+MD），支持异地存储 |
| 富文本编辑器复杂度拖慢进度 | 中 | 选成熟编辑器（TipTap），限制自定义能力 |
| 检索性能不足（万篇级） | 低 | 升级 FTS 方案或引入 MeiliSearch，见 §7 |

---

## 14. 成功指标（上线后观察）

- 连续使用率：上线后每周 3 次以上登录访问；
- 内容沉淀量：月均新增笔记 ≥ 20 篇；
- 检索找回成功率：用户搜索后可定位目标内容的占比 ≥ 80%（主观问卷）；
- 数据零丢失：运行期无内容丢失类问题反馈。
